# Детекция и сегментация планктона на неразмеченных снимках

Ruslan Papina, группа М25-555

Сессионное задание: найти и выделить планктонные организмы на снимках из микроскопа без разметки, только предобученными моделями.

Всё в [plankton.ipynb](plankton.ipynb), ноутбук уже выполнен, картинки и таблицы лежат в `results/`.

## Данные

66 jpg из [Google Drive](https://drive.google.com/drive/folders/1LT2NdDSULHiW3FwzT63ewgVO3pwRRhOW): 65 снимков 2048x1536 и `0005.jpg` 2592x1944 с другой камеры.

Разрешения публиковать снимки в задании нет, поэтому оригиналов в репозитории нет (`data/` в `.gitignore`), в `results/` только уменьшенные копии с боксами и масками.
Если `data/images` пустая, ноутбук сам скачает папку через `gdown`, или вручную:

```bash
gdown --folder https://drive.google.com/drive/folders/1LT2NdDSULHiW3FwzT63ewgVO3pwRRhOW -O data/images
```

## Что делается

1. Анализ снимков (контраст, фон, резкость, размеры объектов, перекрытия) и аугментации: яркость, контраст, шум, размытие, гамма, поворот, отражение, масштаб.
2. Детекция: YOLO11m (одноэтапный) и Faster R-CNN ResNet50-FPN v2 (двухэтапный) с весами COCO. Классы COCO к планктону не подходят, поэтому любой бокс считается объектом, порог 0.05 для обеих. 4 эксперимента: каждая модель на исходных снимках и на 8 аугментациях.
3. Сегментация по одним и тем же боксам Faster R-CNN (`results/segmentation/boxes.json`): GrabCut и SAM 2.1 base с box prompts. Ручные боксы не понадобились.
4. Сводная таблица, ошибки, выводы.

## Запуск

```bash
python3.11 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=-1 plankton.ipynb
```

Или открыть ноутбук в Jupyter и выполнить все ячейки, из корня репозитория. Веса YOLO и SAM 2 скачаются в `weights/`, Faster R-CNN в `~/.cache/torch`.
На MacBook Air M2 (MPS) полный прогон ~8 минут.

## Результаты

| # | модель | данные | время на кадр | боксов | средний score | после аугментаций на месте / IoU |
|---|---|---|---|---|---|---|
| 1 | YOLO11m | 66 исходных | 0.12 с | 753 | 0.17 | |
| 2 | YOLO11m | 66 x 8 аугментаций | 0.11 с | 5492 | 0.18 | 72% / 0.94 |
| 3 | Faster R-CNN | 66 исходных | 0.47 с | 538 | 0.32 | |
| 4 | Faster R-CNN | 66 x 8 аугментаций | 0.47 с | 3979 | 0.31 | 68% / 0.90 |

| метод | время | маска / бокс | маски из 2+ кусков | IoU с другим методом |
|---|---|---|---|---|
| GrabCut | 0.75 с на бокс (CPU) | 0.57 | 6% | 0.82 |
| SAM 2.1 base | 0.16 с на бокс (MPS) | 0.62 | 0% | 0.82 |

Faster R-CNN находит больше рачков и меньше мусора, YOLO в 4 раза быстрее, но ставит много боксов на соринки. Без дообучения обе модели пропускают мелких рачков.
SAM 2 даёт маски заметно лучше GrabCut (щетинки, прозрачный край, разделение соседей), но сильно зависит от бокса.
